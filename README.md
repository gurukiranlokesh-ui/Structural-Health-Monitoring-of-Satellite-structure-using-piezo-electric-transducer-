# 1. Introduction

## 1.1 Structural Health Monitoring

Structural Health Monitoring (SHM) is the process of employing various techniques and technologies to evaluate the state of structures such as buildings, bridges, and satellites in order to assure their safety, dependability, and lifespan.

SHM involves continuous or periodic collection of data related to structural performance and health. This allows the detection of damage, degradation, or other changes that could affect structural integrity.

The main components of SHM are:

1. Sensors
2. Data Acquisition
3. Data Processing

Sensors such as strain gauges, accelerometers, and piezoelectric transducers collect information about structural responses to loads, environmental conditions, and other factors.

Data acquisition is used to collect sensor information either in real time or at predetermined intervals.

Data processing includes signal processing and filtering to clean and prepare the acquired data for analysis.

## 1.2 Need for Structural Health Monitoring

Structural Health Monitoring is important for satellites because the structural condition must be monitored throughout the operational life of the spacecraft.

The main mechanical properties considered in the project are:

- Stress
- Strain
- Volume
- Thermal Properties
- Vibration

# 2. Types of Structural Health Monitoring Methods for Satellite Structures

## 2.1 Strain Gauges

Strain gauges are used to measure strain and deformation, which are important indicators of structural health.

They operate based on the principle that the electrical resistance of a conductor changes when the conductor is subjected to strain.

Strain gauges can be used to detect small structural changes, stress concentrations, and potential failure points.

## 2.2 Accelerometers

Accelerometers are used to measure vibrations and accelerations.

They can be used to study the dynamic response of satellite structures during launch vibrations, orbital manoeuvres, and impacts.

Changes in vibration behaviour can provide information about possible structural abnormalities.

## 2.3 Fiber Optic Sensors

Fiber optic sensors, including Fiber Bragg Gratings (FBGs), can be used for strain and temperature measurements.

Their high sensitivity, immunity to electromagnetic interference, lightweight construction, and flexibility make them suitable for satellite structures.

## 2.4 MEMS Sensors

Microelectromechanical Systems (MEMS) sensors include accelerometers, gyroscopes, and pressure sensors.

Their small size, low weight, and low power consumption make them suitable for aerospace applications.

## 2.5 Thermal Imaging and Temperature Sensors

Thermal imaging and temperature sensors are used to monitor the thermal environment of a satellite structure.

Temperature variations and thermal stress can provide information about insulation problems, abnormal heat generation, and other structural or system-related issues.

# 3. Piezoelectric Transducer for Structural Health Monitoring

Piezoelectric transducers are used in this project for structural health monitoring because of their sensitivity to mechanical stress and strain.

The piezoelectric effect produces an electrical response when a piezoelectric material is subjected to mechanical loading.

Materials such as quartz and Lead Zirconate Titanate (PZT) exhibit piezoelectric behaviour.

The electrical response generated by the transducer can be related to the applied mechanical loading using mathematical models.

## Advantages of Piezoelectric Transducers

1. High sensitivity to stress, strain, and pressure.
2. Wide frequency range.
3. Durability.
4. Direct conversion of mechanical energy into electrical signals.
5. Compact size.
6. Low cost compared with some other sensor technologies.
7. Capability for real-time monitoring.
8. Versatility in aerospace, civil, and mechanical applications.

## Disadvantages of Piezoelectric Transducers

1. Temperature sensitivity.
2. Depolarization.
3. Brittleness.
4. Non-linear behaviour under certain conditions.
5. Limited signal amplitude for small deformations.
6. Signal-processing and power requirements.
7. Environmental effects.
8. Complex installation and positioning requirements.

# 5. Methodology

The proposed Structural Health Monitoring system uses piezoelectric transducers for measuring stress and strain-related structural responses.

An accelerometer is used to detect major and minor vibrations produced by the structure.

Temperature sensors are considered for monitoring the temperature experienced by the structure.

The piezoelectric transducers are connected to an Analog-to-Digital Converter (ADC), which converts the analogue sensor signal into digital form.

The ADC is connected to the main processing system, where the sensor data is collected and processed.

The collected information is transmitted to a ground station using a long-range communication device based on LoRa.

At the receiving end, the transmitted data is processed and passed through signal-processing stages.

Low-pass and high-pass Butterworth filters are used for signal processing and removal of unwanted noise.

After signal processing, the data is supplied to a machine-learning model.

Isolation Forest is used for anomaly detection, and the system also uses Local Outlier Factor for comparison.

The processed data is visualised using graphs such as:

- Time vs Stress
- Time vs Strain
- Time vs Current
- Time vs Vibration

# 7. Parameters Used to Define Healthy and Unhealthy Structures

The project considers four major structural parameters:

1. Stress
2. Strain
3. Vibration Level
4. Temperature

## 7.1 Stress

### Healthy Structure

A healthy structure is considered to have:

- Stress levels within the material yield strength.
- No permanent deformation.
- Relatively even stress distribution.
- Consistent stress patterns during operation.

### Unhealthy Structure

An unhealthy structure may exhibit:

- Stress levels exceeding the yield strength.
- Plastic deformation.
- Uneven stress distribution.
- Fluctuating stress patterns.
- Potential stress concentrations.

## 7.2 Strain

### Healthy Structure

- Strain remains within the elastic limit.
- Uniform strain distribution.
- Strain response agrees with expected structural behaviour.

### Unhealthy Structure

- Strain enters the plastic region.
- Concentrated strain areas may occur.
- Deviations from expected strain behaviour may be observed.

## 7.3 Vibration Level

### Healthy Structure

- Vibration remains within design tolerances.
- Stable vibration frequencies.
- Predictable damping behaviour.
- No unexpected resonance or excessive oscillation.

### Unhealthy Structure

- Increased vibration amplitude.
- Changes in natural frequency.
- Irregular vibration patterns.
- Possible changes in stiffness or mass distribution.

## 7.4 Temperature

### Healthy Structure

- Temperature remains within the operating range of the material.
- Controlled thermal expansion and contraction.
- Controlled thermal gradients.

### Unhealthy Structure

- Temperature exceeds material limits.
- Uneven thermal expansion.
- Uncontrolled thermal gradients.
- Possible thermal degradation or structural distortion.

# 10. Mathematical Model

## 10.1 Stress

Stress is defined as the internal resistance offered by a material against deformation when subjected to an external force.

The basic stress equation is:

```text
σ = F / A
```

where:

```text
σ = Stress
F = Force
A = Area
```

Stress is measured in units such as Pascal (Pa) or pounds per square inch (psi).

### Types of Stress

- Tensile stress
- Compressive stress
- Shear stress

## 10.2 Piezoelectric Stress Measurement

The electric displacement generated in a piezoelectric material due to applied stress is represented as:

```text
D = dT
```

where:

```text
D = Electric displacement
d = Piezoelectric charge constant
T = Mechanical stress
```

The charge is related to electric displacement and piezoelectric area by:

```text
Q = D × A
```

Current is given by:

```text
I = dQ/dt
```

Therefore:

```text
I = A × dD/dt
```

Substituting:

```text
D = dT
```

gives:

```text
dD/dt = d × dT/dt
```

Therefore:

```text
I = A × d × dT/dt
```

Rearranging:

```text
dT/dt = I / (A × d)
```

Integrating with respect to time:

```text
T = 1 / (A × d) ∫ I dt
```

This provides the relationship used in the project to estimate mechanical stress from the electrical response of the piezoelectric transducer.

## 10.3 Strain

Strain is calculated from the change in dimension of the structure.

```text
ε = ΔL / L
```

where:

```text
ε  = Strain
ΔL = Change in length
L  = Original length
```

The piezoelectric charge relation used in the report is:

```text
Q = d × A × σ
```

where:

```text
Q = Charge
d = Piezoelectric charge constant
A = Piezoelectric transducer area
σ = Mechanical stress
```

# 13. Transmitter Software

The transmitter is implemented in Python using the Raspberry Pi.

```python
import smbus2
import time
import datetime
from lora import LoRa
import RPi.GPIO as GPIO
import json
import threading

# I2C addresses
PCF8591_ADDRESS = 0x48
GY87_ADDRESS = 0x68

# Initialize I2C
bus = smbus2.SMBus(1)

# GPIO setup (for LoRa DIO0 pin)
GPIO.setmode(GPIO.BCM)
DIO0_PIN = 17
GPIO.setup(DIO0_PIN, GPIO.IN)

# Function to read from PCF8591 ADC
def read_adc(channel):
    try:
        bus.write_byte(PCF8591_ADDRESS, channel)
        return bus.read_byte(PCF8591_ADDRESS)
    except Exception as e:
        print(f"Error reading ADC channel {channel}: {e}")
        return None

# Function to initialize the GY-87 sensor
def init_gy87():
    try:
        bus.write_byte_data(GY87_ADDRESS, 0x6B, 0x00)
    except Exception as e:
        print(f"Error initializing GY-87: {e}")

# Function to read from GY-87 sensor
def read_gy87():
    try:
        accel_x = bus.read_byte_data(GY87_ADDRESS, 0x3B)
        accel_y = bus.read_byte_data(GY87_ADDRESS, 0x3D)
        accel_z = bus.read_byte_data(GY87_ADDRESS, 0x3F)
        return accel_x, accel_y, accel_z
    except Exception as e:
        print(f"Error reading GY-87: {e}")
        return None, None, None

# Function to initialize LoRa module
def init_lora():
    try:
        lora = LoRa(
            mode=LoRa.LORA,
            region=LoRa.EU868,
            frequency=868.0,
            pins={'dio0': DIO0_PIN}
        )
        lora.set_tx_power(14)
        return lora
    except Exception as e:
        print(f"Error initializing LoRa: {e}")
        return None

# Function to get current time in the required format
def get_current_time():
    return datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S")

# Function to log data locally
def log_data(data):
    with open("data_log.json", "a") as log_file:
        json.dump(data, log_file)
        log_file.write('\n')

# Function to collect sensor data
def collect_data():
    init_gy87()
    lora = init_lora()

    if not lora:
        print("LoRa initialization failed. Exiting...")
        return

    while True:
        current_time = get_current_time()

        pzt1_value = read_adc(0x00)
        pzt2_value = read_adc(0x01)
        pzt3_value = read_adc(0x02)
        pzt4_value = read_adc(0x03)

        accel_x, accel_y, accel_z = read_gy87()

        if None in (accel_x, accel_y, accel_z):
            continue

        vibration = (accel_x 2 + accel_y 2 + accel_z 2) 0.5

        data = {
            'time': current_time,
            'PZT1': pzt1_value,
            'PZT2': pzt2_value,
            'PZT3': pzt3_value,
            'PZT4': pzt4_value,
            'vibration': round(vibration, 2)
        }

        try:
            lora.send(json.dumps(data))
        except Exception as e:
            print(f"Error sending data via LoRa: {e}")

        log_data(data)
        print(data)
        time.sleep(1)

if __name__ == "__main__":
    data_thread = threading.Thread(target=collect_data)
    data_thread.start()
```

The transmitter collects the four PZT values, acceleration data, vibration information, and current time. The data is transmitted through LoRa and stored locally in JSON format.

# 16. Receiver Software

```cpp
#include <ESP8266WiFi.h>
#include <LoRa.h>
#include <ArduinoJson.h>

// LoRa module pins
#define LORA_SCK D5
#define LORA_MISO D6
#define LORA_MOSI D7
#define LORA_SS D8
#define LORA_RST D2
#define LORA_DIO0 D1

// RGB LED pins
#define RED_PIN D1
#define GREEN_PIN D2
#define BLUE_PIN D3

// LoRa settings
const long frequency = 868E6;

void setup() {
    Serial.begin(115200);
    while (!Serial);

    // Initialize RGB LED pins
    pinMode(RED_PIN, OUTPUT);
    pinMode(GREEN_PIN, OUTPUT);
    pinMode(BLUE_PIN, OUTPUT);

    // Initialize LoRa
    if (!LoRa.begin(frequency)) {
        Serial.println("LoRa initialization failed. Check your connections.");
        setLEDStatus("error");
        while (1);
    }

    // Set LoRa module pins
    LoRa.setPins(LORA_SS, LORA_RST, LORA_DIO0);

    Serial.println("LoRa Receiver Initialized.");
    setLEDStatus("no_signal");
}

void loop() {

    // Check if there is any data available to read
    int packetSize = LoRa.parsePacket();

    if (packetSize) {

        setLEDStatus("received");

        Serial.print("Received packet of size ");
        Serial.println(packetSize);

        // Read packet
        String receivedData = "";

        while (LoRa.available()) {
            receivedData += (char)LoRa.read();
        }

        Serial.print("Data: ");
        Serial.println(receivedData);

        // Parse JSON data
        DynamicJsonDocument doc(1024);
        DeserializationError error = deserializeJson(doc, receivedData);

        if (!error) {

            String time = doc["time"];
            int pzt1 = doc["PZT1"];
            int pzt2 = doc["PZT2"];
            int pzt3 = doc["PZT3"];
            int pzt4 = doc["PZT4"];
            float vibration = doc["vibration"];

            Serial.print("Time: ");
            Serial.print(time);
            Serial.print(", ");

            Serial.print("PZT1: ");
            Serial.print(pzt1);
            Serial.print(", ");

            Serial.print("PZT2: ");
            Serial.print(pzt2);
            Serial.print(", ");

            Serial.print("PZT3: ");
            Serial.print(pzt3);
            Serial.print(", ");

            Serial.print("PZT4: ");
            Serial.print(pzt4);
            Serial.print(", ");

            Serial.print("Vibration: ");
            Serial.println(vibration);

        } else {
            Serial.print("JSON deserialization failed: ");
            Serial.println(error.c_str());
            setLEDStatus("error");
        }

    } else {
        setLEDStatus("no_signal");
    }

    delay(1000);
}

// Function to control the RGB LED status
void setLEDStatus(String status) {

    // Turn off all LEDs
    digitalWrite(RED_PIN, LOW);
    digitalWrite(GREEN_PIN, LOW);
    digitalWrite(BLUE_PIN, LOW);

    if (status == "received") {

        // Green LED
        digitalWrite(GREEN_PIN, HIGH);

    } else if (status == "no_signal") {

        // Red LED
        digitalWrite(RED_PIN, HIGH);

    } else if (status == "error") {

        // Blue LED
        digitalWrite(BLUE_PIN, HIGH);
    }
}
```

The receiver waits for LoRa packets, reads the received JSON data, extracts the sensor parameters, and displays them through the serial interface.
